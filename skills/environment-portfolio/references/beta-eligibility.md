# Managed beta eligibility by generation

Reviewed 2026-11-06 against the official guides below. Refresh before a current
claim; this scopes documentation, not proof of any org's entitlement.

- **Fact, managed 2GP:** the promotion guide lists scratch orgs and sandboxes
  for beta installation; an installed beta cannot be upgraded. Do not recommend
  a standalone PDE or Environment Hub Test/Demo org based on the 1GP guidance.
  If evidence conflicts, disclose it and keep that target unconfirmed pending
  2GP-specific proof.
- **Fact, managed 1GP:** its beta guide also lists Developer Edition and
  Environment Hub test orgs. This broader list does not establish 2GP eligibility.
- **Recommendation:** a dedicated eligible sandbox may support persistent
  synthetic data and beta reinstall tests, conditional on access, entitlements,
  and a safe data/configuration preservation plan. A scratch org alone cannot
  prove 90-day persistence. A separate persistent-data store plus scratch beta
  tests does not prove the integrated workflow runs for ninety days.
- A released package may allow a different persistent target. Irreversible
  promotion still needs a separate release decision and approval; it is not a
  shortcut around an unresolved testing prerequisite.
