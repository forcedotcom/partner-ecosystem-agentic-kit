# Managed beta eligibility by generation

Reviewed 2026-11-06 against these official guides; refresh before a current claim.

**Fact:** the managed 2GP promotion guide lists scratch orgs and sandboxes for
beta installation and says an installed beta cannot be upgraded. The managed
1GP beta guide has a broader list including Developer Edition and Environment
Hub test orgs. Do not apply that 1GP list to a 2GP candidate. Disclose conflicting
or unverified target eligibility rather than recommending a Test/Demo beta
path anyway.

**Recommendation:** a dedicated eligible sandbox is conditional on access,
entitlements, and a safe uninstall/reinstall and data-preservation plan. A
scratch org alone cannot satisfy a ninety-day persistence requirement.
Promotion is irreversible and requires a separate approved release decision.
